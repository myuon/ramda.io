# 作品ページを多言語化する手順

## 手順
1. 変更前の HTML と、既定言語（日本語）での表示（本文・title・canvas）を保存する。変更後に既定言語の表示が一致することを比較で確かめる。
2. 文字列を ja / en の辞書にまとめる。数字や計算結果は文字列の外に出し、言語で変わらないようにする。
3. 言語は `?lang=` を最優先し、なければブラウザの言語で決める。切り替えは `history.replaceState` で URL を更新し、他のパラメータと hash を残す。計算や再生の状態は初期化しない。
4. 見出し・属性（aria-label・title・alt）・`document.title`・meta description・canvas に描く文字をすべて訳す。
5. 検証は、ブラウザ（Chromium・WebKit）× 幅（PC・スマホ）× `?lang` × ブラウザの locale（en-US・ja-JP）の組み合わせで行う。
6. 英語表示で既定言語の文字が残っていないかを、DOM と canvas の両方で機械的に走査する。

## Pitfalls
- canvas の文字は DOM に出ないため、DOM だけの走査では漏れる。
- 切り替え後に状態が変わると、比較の基準がずれる。切り替えの前後で状態が同じことも確かめる。
