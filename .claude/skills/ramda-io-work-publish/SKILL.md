# ramda.io に作品を公開する

## 手順
1. 元のファイルは変更せず、`public/works/<slug>/` に置く。
2. title・description・OGP・Twitter カードの meta を付ける。OGP の URL は www.ramda.io に向ける。
3. 作品の見どころが写る場面（分岐、完成図など）をスクショし、サムネイルと OGP 画像を作る。
4. トップページの作品一覧に、Notion を使わない静的なエントリを追加する。
5. ローカルでビルドし、`/works/<slug>/` を開いて、サンプルを最後まで動かす。コンソールエラーがないことと、トップに作品カードが出ることを確かめる。
6. ブランチから PR を作り、Vercel プレビューで同じ確認をしてから rebase でマージする。
7. 本番の URL を開いて反映を確かめ、公開 URL と確認結果を報告する。

## Pitfalls
- 既存の作品を入れ直すときは、元ファイルと公開版の差分を取って取りこぼしを確かめる。自動で当てた箇所（リンクのパスなど）は、周囲が変わっていると誤りやすいので手で確認する。
- 作品の元リポジトリは、ローカルにだけコミットが残っていることがある。公開したと報告する前に、公開リポジトリの main に入っているか確かめる。未 push なら、その旨を報告に書く。
- コミットには、対象ファイルを明示して追加する。`.claude/` などの作業用ディレクトリは含めない。
