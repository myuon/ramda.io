# 上流リポジトリの作品を移植する

上流リポジトリの作品を移植し、自サイト向けの調整を入れ直す手順。

## 手順
1. 移植前に、自サイト向けの調整点を一覧にする（リンク先のパス、OGP・title などの meta、作品名、その他の固有設定）。
2. 上流の最新コミットからファイルをコピーする。
3. 一覧の調整を入れ直す。
4. 上流の元ファイルと移植後のファイルを diff で比べ、調整漏れと意図しない差分がないか確認する。
5. ローカルで移植先のパスを開いて表示させる。
6. インタラクティブな作品なら、サンプルを 1 つ最後まで操作し、コンソールにエラーが出ないことを確認する。
7. 前回と同じ運用で main に反映する。

## Pitfalls
- 調整点を覚えておかないと、再コピーのたびに抜けやすい。
- 作品名の変更はタイトル・見出し・OGP・リンク文言をまとめて確認する。
